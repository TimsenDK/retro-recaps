# Machine photograph credits

Every photograph in this directory was retrieved from Wikimedia Commons and is
licensed individually by its photographer. The licence of this repository's own
data and documentation (CC BY-SA 4.0) does **not** apply to these files — reuse
them under the terms recorded below, and keep the credit with the image.

Licence and author were read from each file's own metadata on Commons
(`action=query&prop=imageinfo&iiprop=extmetadata`) and cross-checked against the
file page's wikitext. Only CC0, CC BY, CC BY-SA and public-domain files were
accepted; nothing carrying NC, ND, "fair use" or an unclear licence is included.

Each machine has a `<machine-id>.jpg` (1200 px on the long edge) and a
`<machine-id>-card.jpg` (480 px) variant. Both are derived from the same Commons
original by downscaling and JPEG re-encoding — no cropping, so the original
aspect ratio and framing are preserved.

## Notes on individual files

- **amiga-2000** and **amiga-3000** are retouched derivatives (background and
  levels adjusted by Commons user Ubcule) of public-domain originals released by
  Trafalgarcircle and by Joeinwap respectively. The originals
  (`File:A2000cpu.jpg`, `File:Amiga3000front.jpg`) carry PD-self tags, so the
  derivatives are free of restrictions; the editor is credited anyway.
- **commodore-128d** is dual-licensed by the author as CeCILL **or**
  CC BY-SA 2.0 FR. CC BY-SA 2.0 FR is used here.
- **commodore-1541-ii** was uploaded under GFDL with `migration=relicense`, so it
  is also available under CC BY-SA 3.0, which is the licence relied on. It is the
  only usable 1541-II photograph on Commons and is small (600 × 422), so no
  1200 px variant exists — the file is stored at its native size.
- **commodore-128dcr** has no photograph on Commons. There is no
  `Category:Commodore 128DCR`, and the images in `Category:Commodore 128D` show
  the plastic-cased 128D, not the metal-cased DCR. No image was substituted.
- **commodore-1541c**: the file is titled "Commodore 1541 white" but its own
  description (by the photographer) identifies the machine as a 1541C — the white
  case with the lever-type door.
